Azure Synapse Analytics is a bridge between two worlds: traditional data warehousing and modern big data processing. In the past, companies had to manage separate tools for SQL databases and big data platforms like Apache Spark. Synapse merges these into a single workspace, allowing data engineers and analysts to ingest, explore, prepare, and serve data for immediate business intelligence and machine learning needs from one central hub.

Why it matters

In the modern data landscape, data arrives in many forms-structured rows in a database, semi-structured JSON files, or unstructured logs. Azure Synapse matters because it provides a unified experience to handle all of them.

  • Unified Interface: You no longer need to switch between different Azure services. Everything from data movement to visualization happens in the Synapse Studio.
  • Scalability: You can scale compute resources up or down depending on the workload, ensuring you only pay for what you use.
  • Hybrid Data Processing: It allows you to query files sitting in a data lake using standard SQL language without first importing them into a database.

Step-by-step walkthrough

1. The Synapse Workspace

The workspace is the top-level container for all your resources. When you create a workspace, it automatically links to an Azure Data Lake Storage (ADLS) Gen2 account. This storage serves as the "source of truth" where all your raw data resides.

2. Understanding Analytic Pools

Synapse uses "Pools" to provide compute power. There are three main types:

  • Serverless SQL Pool: Always available. You use it to query data directly from your data lake using SQL. You are charged only for the amount of data processed per query.
  • Dedicated SQL Pool: This is the evolution of Azure SQL Data Warehouse. It provides high-performance storage and compute for predictable, heavy workloads.
  • Apache Spark Pool: Used for big data processing, data engineering, and machine learning using languages like Python, Scala, or Spark SQL.

3. Data Integration (Pipelines)

Synapse includes the engine of Azure Data Factory. This allows you to create ETL (Extract, Transform, Load) pipelines. You can drag and drop "activities" to move data from over 90 different sources-like an on-premises SQL server or a SaaS platform-into your Synapse environment.

4. Synapse Studio

This is the web-based tool where the work happens. It is divided into several hubs:

  • Data Hub: Browse your databases and linked storage.
  • Develop Hub: Write SQL scripts, Spark notebooks, and Power BI reports.
  • Integrate Hub: Build and manage data pipelines.
  • Monitor Hub: Check the status of your queries and pipeline runs.

Code Example: Querying a CSV file with Serverless SQL

One of the most powerful features of Synapse is the ability to use SQL to look at a file in your storage account without moving it.


-- Querying a CSV file directly from the Data Lake
SELECT
    TOP 100 *
FROM
    OPENROWSET(
        BULK 'https://youraccount.dfs.core.windows.net/container/data/sales_data.csv',
        FORMAT = 'CSV',
        PARSER_VERSION = '2.0',
        FIRSTROW = 2
    ) AS [result]

Common mistakes

  • Leaving Dedicated Pools Running: Dedicated SQL Pools and Spark Pools charge you as long as they are "started." If you aren't using them, pause them (for SQL) or ensure auto-pause is enabled (for Spark) to avoid massive bills.
  • Ignoring Data Distribution: In Dedicated SQL Pools, how you distribute data across nodes (Round Robin, Hash, or Replicated) determines performance. Choosing the wrong one can lead to slow queries.
  • Using the Wrong Tool: Don't use a Spark Pool for a simple data movement task that a Pipeline can do more cheaply, and don't use Serverless SQL for heavy, repetitive reporting that requires dedicated performance.

Practice task

To get started, follow these steps in your Azure portal:

  • Create a new Azure Synapse Analytics workspace and a new ADLS Gen2 storage account during the setup.
  • Upload a small sample CSV file (like a public weather or sales dataset) to your storage account.
  • Go to the Data Hub in Synapse Studio, right-click your CSV file, and select New SQL Script > Select TOP 100 rows.
  • Run the generated script to see how the Serverless SQL pool reads the file instantly.
